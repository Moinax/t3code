# Fork updates

The commit icon at the bottom of the sidebar shows how many commits on
`pingdotgg/t3code`'s `main` branch are missing from the published
`Moinax/t3code` fork's `moinax` branch. Click it to open the full list, newest
first. Search by commit message, author, or SHA, and click a commit to read its
diff on GitHub.

The count compares GitHub branches. It does not reflect unpublished local
rebases, local changes, or the version of the installed app. Commits applied
through cherry-pick can still appear because their commit IDs differ.

Checks run every 15 minutes while the app is active. **Refresh** checks on demand.
If a check fails, the icon shows `!` and the page keeps the last successful result
with its timestamp. GitHub request limits may delay the next check.

This view is available in the fork's desktop app and web client, including a
mobile browser. It does not require a local checkout or a connected project.
